# Cybersecurity Projects

Three defensive security tools written in Python (standard library only), each with unit tests.

| Project | Focus | Folder |
|---|---|---|
| SSH Brute-Force Detector | Log analysis, intrusion detection | `ssh-bruteforce-detector/` |
| Defensive Port & Service Scanner | Network security, attack-surface auditing | `port-scanner/` |
| File Integrity Monitor | Host-based intrusion detection, cryptographic hashing | `file-integrity-monitor/` |

Run any project's tests with `python3 -m unittest discover -s tests` from inside its folder.

All tools are for use on systems you own or are authorised to test.
